# Critérios de Aceitação

Os critérios de aceitação definem as condições mínimas que deverão ser atendidas para considerar as funcionalidades propostas no projeto como implementadas corretamente.

## CA01 - Cadastro e organização dos dados

O sistema deverá permitir o registro e a organização das informações relacionadas aos clientes, veículos, serviços e processos realizados pelo despachante.

**Critério de aceitação:**  
Os dados deverão ser armazenados de forma organizada e poderão ser utilizados posteriormente nas etapas de análise.

## CA02 - Extração dos dados

O sistema deverá permitir a obtenção dos dados necessários para realização das análises.

**Critério de aceitação:**  
Os dados dos processos deverão ser disponibilizados em formato que permita sua utilização pelas ferramentas de Ciência de Dados.

## CA03 - Tratamento dos dados

Os dados deverão passar por etapas de limpeza, tratamento e padronização.

**Critério de aceitação:**  
O processo deverá identificar e tratar dados ausentes, duplicados ou inconsistentes antes da realização das análises.

## CA04 - Geração do dataset tratado

Após o tratamento, deverá ser disponibilizado um conjunto de dados organizado para análise.

**Critério de aceitação:**  
O dataset deverá apresentar dados padronizados e adequados para utilização nas etapas seguintes do projeto.

## CA05 - Análise Exploratória de Dados

O projeto deverá realizar uma Análise Exploratória de Dados (EDA) sobre os processos registrados.

**Critério de aceitação:**  
A análise deverá apresentar informações que permitam compreender as características dos dados e identificar padrões relacionados aos serviços realizados.

## CA06 - Indicadores

A solução deverá gerar indicadores relacionados aos processos do despachante.

**Critério de aceitação:**  
Deverão ser apresentados indicadores como quantidade de processos, situação dos serviços, prazos, atrasos e tempo de conclusão, conforme a disponibilidade dos dados.

## CA07 - Visualização dos dados

Os resultados deverão ser apresentados de forma visual.

**Critério de aceitação:**  
O projeto deverá apresentar gráficos ou outras formas de visualização que facilitem a interpretação dos resultados obtidos.

## CA08 - Dashboard

A solução deverá apresentar um painel com os principais resultados das análises.

**Critério de aceitação:**  
O dashboard deverá reunir os principais indicadores do projeto de forma simples e compreensível.

## CA09 - Documentação

O desenvolvimento deverá possuir documentação das principais etapas realizadas.

**Critério de aceitação:**  
O repositório do projeto deverá conter os requisitos, diagramas, critérios de aceitação e demais documentos necessários para compreender a evolução da solução.

## CA10 - Versionamento

O projeto deverá utilizar Git e GitHub para controle das alterações realizadas.

**Critério de aceitação:**  
As principais etapas do desenvolvimento deverão estar registradas no histórico de commits do repositório.
