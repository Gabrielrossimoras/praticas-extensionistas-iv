# Dados do Projeto

Esta pasta contém os dados utilizados no desenvolvimento do projeto de Práticas Extensionistas IV.

## Organização

Os dados serão divididos em:

- dados brutos: informações originais utilizadas como entrada no pipeline;
- dados tratados: informações após limpeza, padronização e preparação para análise.

Os dados utilizados no projeto serão anonimizados, evitando a exposição de informações pessoais de clientes, veículos ou processos reais.

## Objetivo

Os dados servirão como base para o desenvolvimento do pipeline ETL, para a Análise Exploratória de Dados (EDA) e para a geração dos indicadores do Sistema Inteligente de Controle e Análise de Processos para Despachante.
