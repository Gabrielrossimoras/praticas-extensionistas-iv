# Práticas Extensionistas IV

## Sistema Inteligente de Controle e Análise de Processos para Despachante

Projeto desenvolvido na disciplina de Práticas Extensionistas IV do curso de Ciência de Dados e Inteligência Artificial.

## Sobre o projeto

Este projeto é uma evolução do Sistema de Controle de Documentos para Despachante desenvolvido anteriormente em Práticas Extensionistas III.

A proposta é utilizar técnicas de Ciência de Dados para organizar, tratar e analisar os dados dos processos e atendimentos realizados por um despachante documentalista.

A solução busca transformar os dados dos atendimentos em informações que possam auxiliar no controle de documentos, prazos, serviços e processos.

## Objetivo

Desenvolver a evolução de um sistema de controle de processos para despachante documentalista, utilizando técnicas de Ciência de Dados para organizar, tratar e analisar os dados dos atendimentos, gerando informações que auxiliem no controle de documentos, prazos e serviços.

## Funcionalidades previstas

- Controle de processos;
- Controle de documentos e pendências;
- Controle de prazos;
- Organização dos dados dos atendimentos;
- Pipeline de tratamento de dados (ETL);
- Análise Exploratória de Dados (EDA);
- Indicadores gerenciais;
- Visualização dos dados;
- Dashboard interativo;
- Avaliação da aplicação de técnicas de Machine Learning.

## Tecnologias

- Python
- Pandas
- Google Colab
- Git
- GitHub
- Banco de Dados
- Ferramentas de visualização de dados

## Estrutura do projeto

- `dados/` - bases de dados brutas e tratadas
- `notebooks/` - notebooks utilizados no ETL e nas análises
- `diagramas/` - diagramas e modelagem da solução
- `documentacao/` - documentação do projeto
- `src/` - códigos-fonte da aplicação e do pipeline
