# Código-fonte do Projeto

Esta pasta contém os códigos utilizados no desenvolvimento do Sistema Inteligente de Controle e Análise de Processos para Despachante.

## Pipeline ETL

O projeto utiliza um pipeline ETL para realizar as seguintes etapas:

1. Extração dos dados brutos dos processos;
2. Limpeza e tratamento dos dados;
3. Padronização das informações;
4. Tratamento de valores ausentes;
5. Criação de novas informações úteis para análise;
6. Geração de um dataset tratado.

O processamento será desenvolvido utilizando Python e a biblioteca Pandas.

## Fluxo

Dados brutos → Extração → Transformação → Dataset tratado → Análise Exploratória de Dados (EDA)
